# 📊 Student Performance Analytics Dashboard

A **Student Performance Analytics Dashboard** built using **Python, Pandas, and Streamlit** to analyze student performance data and present meaningful insights through an interactive dashboard.

## 🚀 Project Overview

This project provides an interactive way to analyze student performance data.

Users can upload a student performance CSV file and explore the data through an easy-to-use Streamlit dashboard.

## ✨ Features

- 🔐 Simple login interface
- 📂 Upload student performance CSV files
- 📊 Analyze student performance data
- 📈 Interactive data visualization
- 🧹 Data analysis and processing using Pandas
- 🖥️ User-friendly Streamlit dashboard
- 📑 Performance results and insights

⚙️ Installation
Clone the repository:
git clone https://github.com/sandeepasandy/Student-Performance-Analytics-Dashboard-Project.git

Go to the project folder:
cd Student-Performance-Analytics-Dashboard-Project

Create a virtual environment:
python -m venv venv

Activate the virtual environment on Windows:
venv\Scripts\activate

Install the required libraries:
pip install streamlit pandas

▶️ Run the Dashboard
Run the Streamlit application:
streamlit run app.py

The dashboard will open in your browser.
